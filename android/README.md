# Robottle Medabots para Android

Este módulo empacota o jogo web original como uma aplicação Android offline usando `WebView`. Todo o HTML e as imagens ficam dentro de `app/src/main/assets/game`.

## Abrir e executar

1. Abra a pasta `android` no Android Studio.
2. Aguarde a sincronização do Gradle.
3. Execute o módulo `app` em um emulador ou dispositivo Android.

O projeto exige Android SDK 35 e Java 17. O jogo foi configurado para retrato e não precisa de internet.
